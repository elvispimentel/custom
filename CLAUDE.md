# Como trabalhar aqui

O dono deste repositório é neurodivergente e **não deve precisar lembrar nome de skill**. Você lembra por ele.

## Regras de comportamento
1. Antes de responder, procure a skill que se encaixa (tabela abaixo). Se houver 1% de chance, use.
2. **Diga em uma linha qual skill vai usar e por quê** ("Vou usar `brainstorming` porque isso é criar algo novo").
3. Se o pedido estiver vago, use `brainstorming` ou `grill-me`: **uma pergunta por vez**, nunca lista longa.
4. Respostas curtas, terminando em um próximo passo executável.
5. Se o pedido encaixar em uma skill que não foi usada, sugira no fim: "Quer que eu rode X?".
6. Trabalho longo (5+ passos): use `planning-with-files` para registrar o plano em disco.

## Tipo de trabalho → skill
| Quando for... | Use |
|---|---|
| Ideia nova, app, funcionalidade, "quero criar..." | `brainstorming` → `writing-plans` → `executing-plans` |
| Plano confuso, indecisão, "será que...?" | `grill-me`, `the-fool` |
| App de desenvolvimento pessoal / jornadas / gamificação | `brainstorming`, `domain-modeling`, `frontend-design`, `impeccable`, `ui-ux-pro-max` |
| Site ou página de vendas | `frontend-design`, `impeccable`, `ui-ux-pro-max`, `web-design-guidelines`, `brand`, `banner-design`, `wordpress-pro` |
| Identidade visual, tema, slides | `design`, `design-system`, `brand`, `theme-factory`, `slides` |
| Código React / Next / Tailwind / shadcn | `react-best-practices`, `composition-patterns`, `react`, `nextjs`, `tailwindcss`, `shadcn`, `tanstack-query` |
| CRM, banco de dados, API, webhook (Eduzz, Cakto) | `api-designer`, `architecture-designer`, `postgres-pro`, `sql-pro`, `fullstack-guardian`, `php-pro`, `secure-code-guardian` |
| Agentes de IA, RAG, MCP, prompts | `prompt-engineer`, `rag-architect`, `mcp-builder`, `mcp-developer` |
| Bug, erro, "não funciona" | `systematic-debugging`, `debugging-wizard` |
| Testar o que foi feito | `webapp-testing`, `playwright-expert`, `test-driven-development`, `verification-before-completion` |
| Revisar código / segurança | `code-reviewer`, `security-reviewer`, `sharp-edges`, `differential-review`, `second-opinion` |
| Pesquisar o que está em alta (últimos 30 dias) | `last30days` |
| Procurar skill que não existe aqui | `find-skills` |
| Terminar e entregar | `verification-before-completion`, `finishing-a-development-branch` |
| Muitas tarefas independentes | `dispatching-parallel-agents`, `subagent-driven-development` |

## Projeto GSD
Comandos `/gsd-...` estão instalados (ex.: `/gsd-new-project`, `/gsd-progress`, `/gsd-help`). Sugira quando o trabalho pedir fases e roadmap.

## Segurança
`git-guardrails-claude-code` bloqueia comandos git destrutivos. Nunca force push nem apague branch sem confirmação.
